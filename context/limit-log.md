# Usage Limit Log

One line each time a Claude usage limit gets hit. Started 2026-07-31 per the /council
verdict on the production-categories proposal. Review after four weeks (~2026-08-28).

Format: `YYYY-MM-DD — what I was doing when it hit`

The question this answers: is the limit being eaten by work a cheaper model or an
existing script could have done (→ routing is a real problem), or by creative and
judgment work that legitimately needs the top tier (→ question stays closed)?

Threshold: 4+ entries in the first category reopens the routing question with real data.
